# Pose Landmarker Model Asset

The module bundles the official `pose_landmarker_full.task` model used by the demo. SHA-256: `4eaa5eb7a98365221087693fcc286334cf0858e2eb6e15b506aa4a7ecdcec4ad`. The download endpoint is Google's public MediaPipe model distribution:

`https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_full/float16/1/pose_landmarker_full.task`

`MediaPipePoseEstimator` also accepts an alternate compatible task path. Review the MediaPipe repository license and current model distribution terms before distributing modified or replacement assets.
